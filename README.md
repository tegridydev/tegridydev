# [td] tegridydev

**opensource dev | independent researcher | nerdstuff**

I build local tools, open datasets and practical research projects around security, language models and things that interest me.

Most of my work starts as a question or a tool I wanted for myself. If it turns out useful, I clean it up and put it online.

[Website](https://tegridydev.com) · [Hugging Face](https://huggingface.co/tegridydev)

## Current interests

AI security · Local LLMs · Dataset engineering · Mechanistic interpretability · Multi-agent systems · Cool stuff · OSINT · Physical security systems

## Selected work

- **[auto-md](https://github.com/tegridydev/auto-md)** — Turn files, folders and GitHub repositories into clean Markdown for LLM and RAG workflows.
- **[abstract-agent](https://github.com/tegridydev/abstract-agent)** — Local multi-agent research workflow for exploring literature, novelty and hypotheses.
- **[Mechanistic Interpretability](https://github.com/tegridydev/Mechanistic-Interpretability) / [MechaMap](https://github.com/tegridydev/mechamap)** — Research notes and open tools for inspecting transformer internals.
- **[multi-agent-secops-llm](https://github.com/tegridydev/multi-agent-secops-llm)** — Experiments with LLM agents for security operations and analysis.
- **[physical-security-dev](https://github.com/tegridydev/physical-security-dev)** — Practical notes for CCTV, access control and physical-security development.
- **[Python OSINT Notebook](https://github.com/tegridydev/python-OSINT-notebook)** — OSINT tooling, Python automation and intelligence workflows.
- **[dnd-llm-game](https://github.com/tegridydev/dnd-llm-game)** — Local multi-LLM role-playing and interactive storytelling.
